## 1. 本次修正：评分只评价装备完成度

装备评分不是角色战斗力，不把暴击、控制、宠物增益等效果强行折成同一种DPS。评分统一评价装备自身的培养完成度、词条档位完成度；词条类型价值另以流派适配标签显示。这样避免把生存词条错误评价为低级词条，也避免评分最高就等于所有流派最优。

原V1中“固定属性40%、培养20%、普通词条25%、铭纹/武器特性15%”存在重复计算风险，V1.1以本页公式替代。V2的Ppanel与Pcomposite保持原样，不与装备评分混用。

## 2. 防具评分公式（72件防具通用）

防具每件最多3个词条槽；金装第三槽可以由铭纹替换普通词条，仍然只有3个槽。评分分成基础完成度700分和词条完成度300分。

基础完成度：

- 品质系数Q：蓝0.50、紫0.75、金1.00（读取V2 relative\_gold\_factor）。
- 培养系数G=(1+0.05×强化级)×(1+0.02×星铸级)。
- 金装满培养参考系数为1.80。
- BaseScore=700×Q×G/1.80。

词条完成度：

- 档位权重：低5、中8、高12（沿用V2词条档位权重）。
- 普通词条品质系数：蓝0.40、紫0.64、金1.00（沿用V3）；F04锐眼不乘品质系数，按1.00计算。
- 每个词条槽最高100分：AffixSlotScore=100×(档位权重/12)×词条品质系数。
- 铭纹只出现在金装第三槽，按铭纹自身低/中/高档位权重5/8/12计算，品质系数1.00。
- AffixScore=三个槽位分数之和；空槽计0。部位词池、重复规则与全身上限仍按V3执行；被全身上限截掉的溢出词条不计分。

最终防具评分：EquipmentScore=round(clamp(BaseScore+AffixScore,0,1000))。

此公式衡量培养和词条档位，不给不同词条类型主观加分。高档锐眼和高档蛮力可得到相同槽位完成度分，但详情页分别标注“暴击构筑”和“攻击构筑”，推荐排序再按玩家当前流派计算。

## 4. 武器评分公式（32把武器通用）

V2把32把武器的满金主目标持续预算归一化为1.0A/秒；武器没有新增随机词条槽。因此武器评分只评价品质与培养完成度，武器特性不额外赠分，避免把控制、格挡、范围等不同定位强行换算成同一战力。

- Qweapon：蓝1、紫1.5、金2（读取V2 weapon\_quality.quality\_multiplier）。
- Gweapon=(1+0.05×强化级)×(1+0.02×星铸级)。
- WeaponScore=round(1000×Qweapon×Gweapon/3.60)，限制0—1000。

| 品质/培养 | 武器评分 |
| --- | --- |
| 蓝0 | 278 |
| 蓝+5 | 347 |
| 紫0 | 417 |
| 紫+5 | 521 |
| 金0星铸0 | 556 |
| 金+10星铸+10 | 1000 |

武器独有机制、单体DPS/A、群体DPS/A、射程、冷却、控制与动作风险在评分旁显示为独立标签/性能面板，不参与装备评分。武器的实际选择仍按目标类型与玩家操作习惯，不按评分一键判定优劣。未来如需把机制价值纳入分数，必须先建立同定位武器组的实测效用基准，再升评分版本。

## 8. 评分刷新、存档与反作弊

- 评分由服务器读取装备原始实例、品质、强化、星铸、词条与铭纹计算；客户端只展示，不提交评分结果。
- 洗练候选生成时旧词条仍生效；只有玩家确认替换后才重算评分。候选未确认时禁止再次洗练或分解，沿用V3事务规则。
- 升品、强化、星铸、跨岛传承、词条替换、铭纹启用变化后即时重算；装备是否穿戴不影响单件评分。
- 角色装备总评分=当前装备槽内武器评分+五件防具评分。缺槽计0；宠物、神宠、炮台、套装外部临时Buff不加进装备总评分。
- RatingVersion、RatingScore、RatingStar、RatingBreakdown、RatingStatus写入缓存；原始属性才是权威，缓存可随版本重建。

## 9. 验收样本

- 蓝0、蓝+5、紫0、紫+5、金0、金+10星铸+10六种培养边界的武器与防具结果必须与公式一致。
- 防具0/1/2/3条词条、低/中/高档、F04锐眼、金装铭纹替换第三条、同件重复F01—F04、全身上限溢出均要覆盖。
- 72原型×3品质=216条防具品质实例；32原型×3品质=96条武器品质实例，合计312条实例配置必须有评分规则键。
- 评分不影响伤害、怪物血量、掉率、匹配、PVP公平规则、标准宠物积分赛或商城价格。
