## 1. 目标与适用范围

所有可穿戴装备实例都必须显示装备评分与星级：32把武器、72件防具，以及后续新增的可装备物品。五个防具槽（头环、肩甲、护手、护膝、翅膀）与独立武器槽分别使用自己的同槽基准。装备收藏、未穿戴实例也显示评分；评分不因是否穿戴而变化。<br />评分回答“这件装备在自身等级、部位与品质规则下完成度如何”，不直接回答“我的整套角色能打多少伤害”。角色总评分另行汇总，不允许把装备评分直接当作Pcomposite、DPS或胜率。

## 3. 核心评分方法

采用同岛、同有效等级、同装备槽、同装备类别的归一化评分，避免跨岛或跨部位直接比较造成误导。

- 有效等级Le沿用V2：clamp(角色等级,本岛入口级,本岛末级)。
- 固定属性价值沿用V2面板预算：Cfixed=HP/10+2×ATK+DEF。
- 百分比、触发、宠物/炮台协同等功能效果统一换算为评分等价预算Cfunction。换算表按词条ID、档位、部位、触发频率与适用对象维护，必须有版本号；未完成校准的效果不允许猜值，暂列“未校准”并不计入评分。
- Citem=Cfixed+Cfunction+Cweapon。防具的Cweapon=0；武器的伤害动作、完整循环、射程/控制等效果，按V2武器预算函数折算成Cweapon，不能把武器动作倍率再重复加成面板攻击。
- Cref是该岛、该有效等级、该槽/类别下的合法满培养参考预算。参考实例必须满足现行资格、槽位、词条数、铭纹启用上限、强化/星铸上限与1极裁剪规则。
- RawScore=1000×Citem/Cref；EquipmentScore=clamp(round(RawScore),0,1000)。<br />为防止多词条/高属性导致评分越过合法上限，先按服务器最终有效快照应用全局上限、互斥、来源去重与1极裁剪，再计算评分。不能使用客户端提交值。

## 4. 评分构成与显示

评分详情拆成以下四项，合计1000分上限；各项由同槽参考预算归一化，不使用简单固定加分：

| 构成 | 评分权重 | 计算依据 |
| --- | --- | --- |
| 固定属性 | 40% | HP、ATK、DEF按V2的HP/10+2ATK+DEF折算 |
| 品质与培养 | 20% | 蓝/紫/金品质倍率，以及合法强化、星铸对固定属性的实际贡献 |
| 普通词条 | 25% | 普通词条经效果等价预算表换算；重复词条按实际边际收益计分 |
| 铭纹/武器特性 | 15% | 金装铭纹或武器固有机制按合法触发频率和完整循环折算 |
| 各项不是独立赠分。实际实现按Citem/Cref计算，再将总分按以上权重拆分展示；不能把品质倍率先计入固定属性后又在品质项重复计分。若某件装备没有铭纹，15%项按其可用的武器固有机制或同槽固定属性预算重新归一化，不能因此天然低分。 |  |  |

## 5. 武器与防具的差异

防具使用V2固定属性预算与V3词条等价预算。头环、肩甲、护手、护膝、翅膀分别有独立Cref，不把肩甲的防御预算与护手攻击预算直接作原始值比较。<br />武器使用完整动作周期与伤害包预算。主目标、合法副目标、DOT、弹丸、冷却、换弹和动作中断均按V2武器规则处理。武器评分比较同岛同等级同类型/定位的合法武器；若武器具有不同定位（单体、群体、持续、控制），详情页显示定位标签和分项，不以群体理论伤害无条件压过单体武器。

## 6. 词条与铭纹评分规则

1. F01—F20普通词条按效果等价预算表评分，不按词条名字或稀有度主观加分。
2. 同件重复词条按边际收益计算；触及全身上限后的溢出部分计0分。
3. M01—M08铭纹按冷却、触发条件、有效覆盖时间、合法来源与目标数量折算；铭纹替换第三条普通词条后，只计算铭纹，不再计算被替换词条。
4. 攻速、暴击、穿防、移速、控制、治疗、护盾、宠物和炮台增益必须采用各自效果模型；禁止把百分比直接当同百分比战力。
5. 仅PVE生效的词条在PVP/标准宠物积分赛的评分页显示“模式不生效”，不将其作为公平竞技评分。
6. 未校准词条显示“评分待校准”，保留属性效果但不虚构评分贡献；整件评分标记“暂定”，直到校准完成。

## 8. 装备总评分与排序

角色装备总评分=已装备武器评分+五个防具槽评分，缺槽按0分；收藏装备不计入角色总分。总评分只用于角色展示、筛选与推荐，不参与伤害、掉落、匹配、BOSS血量或付费权益计算。<br />排序默认先看星级，再看评分；同分时依次比较装备定位适配、有效词条数量、培养成本。提供“评分排序”和“适合当前流派排序”两种视图。流派推荐需要基于当前武器、宠物、炮台与模式重新计算，不允许把单一评分最高装备自动设为最优装备。

| 评分是派生数据，不是可交易属性，不可由客户端修改。装备升级、升品、强化、星铸、洗练、铭纹刻印/替换、跨岛传承、词条上限变化、评分公式升级时重新计算。存档可缓存评分，但服务器必须能从实例原始字段重建并核对；重复请求保持幂等。公式升级保留旧版本号并批量重算，不因重算改变装备原始属性或收费。 |  |  |

## 10. 验收清单

- [ ] 32把武器与72件防具全部具有评分、星级和评分版本。
- [ ] 八岛入口/末级、蓝/紫/金、强化/星铸边界样本均可重算。
- [ ] 五个防具槽之间不直接比较原始固定属性。
- [ ] 武器动作周期、DOT、多弹丸、群体预算不重复计分。
- [ ] 词条重复、上限溢出、铭纹替换普通词条不双计。
- [ ] 1极裁剪前后评分与服务器最终有效快照一致。
- [ ] 换装不改变单件评分；只改变角色装备总评分。
- [ ] PVP与标准宠物积分赛明确显示模式生效状态。
- [ ] 评分公式升级可重算，不改原始实例属性、不重复扣费。
