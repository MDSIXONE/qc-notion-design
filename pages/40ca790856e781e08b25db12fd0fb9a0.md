## 3. 装备生成服务器流程

1. 检查角色等级、岛屿解锁、奖励资格、来源是否有权生成装备。
2. 按来源掉落表确定装备原型与装备品阶；制造/固定奖励直接读固定品阶，不再随机。
3. 根据品阶概率确定AttributeCount并立即保存随机流状态。
4. 读取部位词池、品阶可用规则和全身属性上限，逐槽抽取合法AttributeId。
5. 计算每条AttributeMax，再抽取RollQuality并得到CurrentValue。
6. 若为传说装备第三槽，按铭文规则确定普通词条或铭文候选；未获得铭文资格/材料时不自动免费赋予铭文。
7. 生成EquipmentInstanceId，写入品阶、属性条数、每条属性ID/值/上限版本、培养等级、生成来源与随机种子标识。
8. 服务器计算EquipmentScore与EquipmentStar，保存实例后才向客户端发放。
9. 如果生成中途失败，整笔事务回滚；同一RequestId重试返回同一实例，不再次抽取。

## 4. UI规格

### 4.1 装备卡片

- 左上角显示品阶文字：普通/优秀/精良/卓越/传说；不再显示蓝紫金。
- 右上角显示评分星级（1—5星）。
- 名称下方显示评分数字，例如“评分 82,436,190”。
- 属性摘要最多显示前2条，其余显示“另有N条属性”。
- 装备排序提供评分从高到低、品阶从高到低、适合当前流派三个入口。

### 4.2 装备详情

- 显示品阶、装备等级Le、部位、套装、强化、星铸。
- 显示“属性数量 N/6”和评分“xx/100,000,000”。
- 每条属性显示名称、当前数值、完成率百分比与当前值/最高合法值。
- 属性进度条按完成率显示，不按属性绝对值显示。
- 铭文显示独立图标、效果、等级、触发条件与冷却。
- 显示“评分仅用于装备比较，不增加战斗属性”的说明入口。

### 4.3 洗炼窗口（依据用户参考图）

- 左侧：装备图、名称、品阶、装备评分、评分星级。
- 右侧左右两栏：当前属性 / 洗炼结果；每条显示名称、数值、完成率。
- 玩家选中要替换的旧属性后，右栏生成3个候选；其余属性锁定不动。
- 选中候选后显示：当前评分、预览评分、评分变化（正负整数）。
- 跨属性候选使用新属性自己的最高合法值计算完成率。
- 确认按钮在选中候选后可用；确认前二次显示替换内容与评分差；取消保留原装备。
- 普通洗炼不洗铭文；铭文刻印/更换使用独立界面和材料事务。

## 5. 评分内核伪代码

```txt
function calculateEquipmentScore(item):
    assert item.attributeCount == length(item.attributeLines)
    totalRatio = 0
    for line in item.attributeLines:
        maxValue = getAttributeMax(item.grade, item.effectiveLevel, item.slot, line.attributeId)
        effectiveValue = applyGlobalCapsAndSourceRules(item, line)
        ratio = clamp(effectiveValue / maxValue, 0, 1)
        totalRatio += ratio
    score = floor(100000000 * totalRatio / 6)
    star = mapScoreToStar(score)
    return score, star
```

实际实现需使用定点/大数精度，不可用客户端浮点数作为权威值。属性Max为0或缺失时应拒绝该配置并记录错误，不允许除零或默认给满分。

## 6. 必须测试的边界

| 测试 | 预期结果 |
| --- | --- |
| 0条属性 | 0分，生成器通常应拒绝空属性装备，Legacy例外 |
| 1条属性100% | 16,666,666分 |
| 6条属性100% | 100,000,000分 |
| 6条属性均50% | 50,000,000分 |
| 3条属性100%、3条空槽 | 50,000,000分 |
| 任一属性当前值大于上限 | Ratio封顶100%，保留原始值并告警 |
| AttributeMax缺失或为0 | 配置错误，不发装备 |
| 跨属性洗炼 | 新属性使用新AttributeMax |
| 洗炼候选取消 | 原属性、评分、资源均不变 |
| 洗炼确认重试 | 只扣一次，结果一致 |
| 重登/交易/换装 | 装备条数与评分不变 |
| 品阶迁移 | 保留旧实例ID、属性与培养，不重新抽取 |
| 铭文重复ID | 第二枚不能启用 |
| 全身已启用2枚铭文 | 第三枚显示灰显，不触发 |

## 7. 实战平衡验收

装备评分本身不改变战斗，但装备品阶和属性上限会改变实际构筑。每个岛至少测试：普通/精英/BOSS，单人/四人，30秒爆发/180秒持续；纯攻击、暴击、双通道DOT、驭兽、炮台、生存六类构筑。对比装备成长前后的TTK、有效生命、宠物输出、炮台输出与资源毕业周期。输出流同资源单体持续DPS的差异先以±10%为预警线；超过15%必须回看属性上限与效果模型。此为验收目标，不是已通过结果。
